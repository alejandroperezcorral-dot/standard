Buying Tool FW26 — Reference

Negotiation, cost modelling and product sheet tool. All calculations are performed client-side in real time.

Core Formulas

MetricFormulaExplanation
Transport / unitcu = (route_cost × ceil(units / load_norm)) / unitscontainers = ceil(units / load_norm). load_norm (units per container) is looked up from the Duties table by country + category. If no record exists, it is estimated: load_norm = container_vol / (weight_kg × 1.001 × (1 + opt_ratio)).
Duty / unitcust = duty_fixed + FOB × duty_%duty_fixed (USD per unit, fixed amount) and duty_% (ad valorem rate) are looked up from the Duties table by destination country + product category. Default rate is 13% when no record is found.
LDPLDP = FOB + cu + custLanded Duty Paid cost in USD per unit. Represents the total cost to get one unit into the warehouse, including purchase price, freight, and customs. This is the cost basis for all margin calculations.
RRP (USD)pU = RRP_rub / rate_USD_RUBRetail price in local currency (RUB) converted to USD at the active exchange rate. All margin calculations use USD throughout so that multi-origin comparisons are currency-neutral.
IMUIMU = (pU − LDP) / pUInitial Markup — gross margin at full retail, expressed as a fraction of RRP. IMU = 0.72 means cost (LDP) represents 28% of the retail price and 72% is margin. This is the primary KPI for buying decisions. Target is configurable per line.
Markup (MU)MU = IMU / (1 − IMU)Cost-on-cost multiplier. Answers: "How many times the LDP is the retail price?" At IMU = 72%: MU = 0.72 / 0.28 = 2.571, so retail is 2.57× the landed cost. Used in wholesale and markdown modelling.
Gapgap = IMU − target_IMUSigned difference in percentage points between the achieved IMU and the line's target. Positive = above target (good). Negative = margin shortfall that must be recovered through FOB renegotiation or RRP adjustment. Displayed in the calculator and negotiation table.
FOB TargetFOB* = (pU × (1 − target_IMU) − cu − duty_fixed) / (1 + duty_%)The maximum FOB price that yields exactly target_IMU given the current freight route and duty rates. Derived by setting IMU = target and solving for FOB. Transport cost cu is computed at current units. Use FOB* as the ceiling in supplier negotiation.
HODHOD = FSD − transit_daysHand-Off Date — the latest date by which goods must leave origin to arrive by the First Sale Date (FSD). transit_days is the shipping time in calendar days from the Freight Routes table, keyed on origin country + transport mode (SEA-TRUCK, SEA-TRAIN, AIR, etc.).
Duty % on FOBcustPct = cust / FOBTotal customs cost (fixed + ad valorem) expressed as a fraction of the FOB price. Allows comparison of the effective customs burden across categories and origins regardless of absolute price level.

Workflow

  1. Select Origin and Transport — the supplier list and transport modes filter to matching freight routes.
  2. Enter RRP and FOB R1 — IMU, LDP, FOB Target and Gap update in real time.
  3. Record rounds R1, R2, R3 as negotiation progresses. FOB Closed locks the final agreed price.
  4. Set FSD — HOD is computed automatically from the freight route days.
  5. Fill Channels %, ST % and life-cycle weeks for planning output.
  6. Click Add line — row appears in the Negotiation table.
  7. Set status to CLOSED — row moves to the Closed tab and FOB Closed is used for all margin calculations.

Tabs & Sections

NegotiationLive pricing table. All cells editable inline. Double-click any row to load it in the sidebar calculator.
ClosedConfirmed orders. Filter by Dept, Supplier, Origin, Category. Export to XLS or generate PDF product sheets.
DashboardAggregated view by origin, supplier, department and sell-through channel mix.
FreightFreight routes table (origin + mode → cost USD + transit days). Cost simulator by transport mode.
DutiesDuty rates by country and category: fixed USD per unit + ad valorem %. Also stores load_norm (units / container) used to compute freight cost per unit.
SettingsExchange rates (USD/RUB, USD/AED, EUR/USD), container volumes, optimization ratio, suppliers, departments and categories. Export / import via XLS.

PDF Product Sheets

  1. Go to the Closed tab.
  2. Select specific articles using checkboxes, or leave all unchecked to include all closed lines.
  3. Click Product Sheets PDF — a full-screen preview opens.
  4. Configure the page header (Title, Subtitle, Department, Date) in the popup.
  5. Click Print / Save PDF — set page size A4 Landscape, margins None.
Layout: 2 columns × 2 rows = 4 product cards per A4 landscape page. Each card shows FOB, LDP, IMU, channels, ST%, photos and key dates.
Quick Ficha — available from the sidebar while filling a new article. Generates a single-card sheet in the top-left of an A4 page without requiring the article to be closed first.
